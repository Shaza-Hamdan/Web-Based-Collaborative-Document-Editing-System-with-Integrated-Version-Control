# Web-Based Collaborative Document Editing System with Integrated Version Control

## About The Project

This is my Master's thesis project at Moscow Aviation Institute (MAI), Institute №3 "Control Systems, Informatics and Electrical Power Engineering", Department 304 "Computers, Systems and Networks".

The system allows multiple users to collaboratively edit documents while maintaining structured version control. It integrates a robust version control mechanism that enables users to track changes, branch, merge, and revert to previous versions—all through an intuitive interface designed for non-technical users.

---

## Why This Project Exists

Existing collaboration tools have limitations:
- **Google Docs, Microsoft 365, Notion**: Provide real-time editing but lack full version control capabilities
- **ONLYOFFICE DocSpace**: Creates versions only on manual save
- **GitHub**: Offers full version control features but is too complex for non-technical users

This system bridges the gap by combining **simple document editing** with **powerful Git-like version control** in an accessible interface.
